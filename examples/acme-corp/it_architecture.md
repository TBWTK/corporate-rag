# Документация по IT-инфраструктуре

ACME ID является единым поставщиком идентификации для CorpMail, Connect, Service Desk, HR Portal,
CRM, GitLab и BI. Многофакторная аутентификация обязательна. Удалённый доступ к внутренним системам
идёт через Corporate VPN с управляемого устройства; прямой вход из публичной сети запрещён.

Внутренние сервисы разделены на пользовательскую, прикладную и административную зоны. GitLab и
CI/CD находятся в инженерном сегменте, CRM — в коммерческом, HR Portal — в кадровом. Обмен между
зонами разрешается через опубликованные API и сервисные учётные записи; общие пароли запрещены.

Журналы входов хранятся 180 дней, административные действия — 365 дней. Об инциденте сообщают по
номеру 7711. Изменения инфраструктуры оформляются заявкой, проходят review и выполняются через CI/CD;
ручное изменение production допускается только при аварии с последующим протоколом.
