# Настройка почтовой подписи

Обязательный шаблон:

**Имя Фамилия**  
Должность · Подразделение  
Acme Corp  
Рабочий телефон · `name.surname@acme.demo`

Название должности берётся из HR Portal без самовольных сокращений. Личный номер телефона,
неутверждённые логотипы, цитаты и рекламные баннеры добавлять нельзя. Для общего адреса поддержки
вместо имени используется «Команда поддержки Acme Corp».

Подпись создаётся отдельно для новых писем и ответов. После настройки сотрудник отправляет тестовое
письмо наставнику; тот проверяет имя, должность, подразделение и отсутствие личных данных.
