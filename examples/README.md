# Демо-набор Acme Corp

`acme-corp/` — связанный корпус из 50 файлов для проверки ingestion, retrieval, цитат и
уточняющего диалога. Seed запускается командой `make demo`; повторный запуск не создаёт дубликаты.

Корпус охватывает восемь форматов: TXT, Markdown, CSV, HTML, DOCX, PDF, XLSX и PPTX. Базовые
политики дополняют 10 соглашений по удалённой работе, сменам, бонусам и командировкам. Разные
правила действуют для продаж, инженерии, продукта, финансов, поддержки, дизайна и регионов,
поэтому вопросы без подразделения, роли, региона или вида расхода должны приводить к уточнению.

Расширение включает трудовой договор и условия труда, графики/форматы работы, пять обязательных
корпоративных политик, культурный код, план адаптации 30–60–90, флеш-тренинги, расшифровки
видеовизиток подразделений, обучение по продукту, IT-архитектуру и инструкции по рабочему месту,
почте, подписи и доступам. Все данные синтетические.

Проверочные сценарии находятся в `demo_cases.json`:

- `answer` — вопрос содержит достаточно контекста для однозначного ответа;
- `clarification` — система должна запросить один недостающий атрибут;
- `two_turn` — ответ на уточнение в том же диалоге должен привести к итоговому правилу.

Всего задано 36 кейсов — по 12 каждого типа. Поле `source_files` связывает ожидаемый результат
с конкретными документами и проверяется автоматическим тестом.

Файл кейсов расположен вне `acme-corp/` и не индексируется. Генераторы бинарных документов
находятся в `scripts/generate_demo_documents.py`, `scripts/generate_demo_workbooks.mjs` и
`scripts/generate_demo_presentation.mjs`.
