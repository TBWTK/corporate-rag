# Демо-набор Acme Corp

`acme-corp/` — связанный корпус из 20 файлов для проверки ingestion, retrieval, цитат и
уточняющего диалога. Seed запускается командой `make demo`; повторный запуск не создаёт дубликаты.

Корпус охватывает восемь форматов: TXT, Markdown, CSV, HTML, DOCX, PDF, XLSX и PPTX. Базовые
политики дополняют семь соглашений по удалённой работе, бонусам и командировкам. Они специально
задают разные области действия и приоритеты, поэтому вопросы без подразделения, категории или
вида расхода должны приводить к уточнению.

Проверочные сценарии находятся в `demo_cases.json`:

- `answer` — вопрос содержит достаточно контекста для однозначного ответа;
- `clarification` — система должна запросить один недостающий атрибут;
- `two_turn` — ответ на уточнение в том же диалоге должен привести к итоговому правилу.

Файл кейсов расположен вне `acme-corp/` и не индексируется. Генераторы бинарных документов
находятся в `scripts/generate_demo_documents.py`, `scripts/generate_demo_workbooks.mjs` и
`scripts/generate_demo_presentation.mjs`.
