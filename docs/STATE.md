## Decisions made

- Страница PDF/DOCX является стабильной единицей provenance и изображением источника.
- Для надёжного анализа встроенных скриншотов документ сначала рендерится; исходный PDF/DOCX
  не передаётся модели как непрозрачный текстовый attachment.
- Один вызов vision обрабатывает одну страницу: это сохраняет точную привязку шага к источнику.
- Обычный pytest остаётся офлайн; реальный GigaChat eval запускается отдельно и осознанно.
- Generation context может содержать полную последовательность шагов, но UI sources должны быть
  отдельной компактной проекцией только процитированных уникальных страниц.
- Неоднозначность между несколькими visual-документами разрешается детерминированно до generation;
  явное имя приложения в следующем сообщении ограничивает контекст одним документом.
