# Текущее состояние

## Active objective

Дополнить доказуемый текстовый ответ встроенным визуальным туториалом из уже извлечённых страниц
документов: автоматически показывать страницы одного подходящего файла и давать явный выбор, если
визуальные источники ответа относятся к нескольким файлам.

## Acceptance criteria

- [x] Источники с изображениями группируются по документу, дубликаты страниц удаляются, страницы
  располагаются в естественном порядке.
- [x] Если визуальный документ один, его страницы автоматически появляются сразу после ответа как
  крупная пошаговая галерея с понятными подписями и ссылкой на полноразмерную страницу.
- [x] Если визуальных документов несколько, интерфейс предлагает выбрать конкретный туториал и
  показывает страницы выбранного документа без нового запроса к модели.
- [x] Обычные источники и текст ответа сохраняются; ответы без изображений не меняются.
- [x] Данные модели не вставляются как HTML, а изображения загружаются только по URL источников,
  уже возвращённым API.
- [x] VPN-сценарий проверен в браузере на desktop и узком viewport; целевые и полные тесты, lint и
  project-control audit проходят.

## Current verified state

- Исходный VPN DOCX проиндексирован в 12 chunks: native text, точная внешняя ссылка и страницы 1–4.
- Текстовый ответ уже содержит полный путь от скачивания архива до проверки VPN и кликабельную
  SharePoint-ссылку.
- До изменения страницы были доступны только внутри раскрываемых карточек источников; встроенной
  визуальной последовательности в исходной версии не было.
- Реализована клиентская группировка по `document_id`, дедупликация по `image_url`, сортировка по
  номеру страницы, автогалерея одного документа и явный выбор для нескольких документов.
- Live VPN browser QA: один DOCX автоматически показал четыре страницы в порядке 1–4; все PNG
  загрузились с размером 1191×1684, desktop и viewport 390×844 не имеют horizontal overflow.
- Live multi-file QA: Outlook/iOS показал две кнопки; после выбора отображается только выбранный
  файл, `aria-pressed` обновляется, новый LLM-запрос не выполняется; console errors/warnings нет.
- Regression: `67 passed`, `2 skipped`, branch coverage 85,27%; Ruff и strict mypy прошли.
- Исходное состояние перед изменениями: `main` совпадает с `origin/main`, worktree чистый.

## Changed areas

- Изменены web UI, адаптивные стили, runtime tests, README, пользовательская, архитектурная,
  quality и roadmap документация.

## Decisions made

- Визуальный туториал дополняет, но не заменяет текстовый ответ и проверяемые карточки источников.
- Выбор между документами выполняется локально по уже найденным источникам, поэтому не расходует
  дополнительный LLM-запрос и не меняет retrieval.
- Автопоказ допустим только при одном визуальном документе; несколько документов требуют явного
  выбора пользователя, чтобы не смешивать разные инструкции.

## Non-goals

- Автоматический выбор одного документа, когда ответ действительно содержит несколько визуальных
  руководств.
