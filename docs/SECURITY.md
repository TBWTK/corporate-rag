# Модель угроз

## Защищаемые активы

Корпоративные файлы, извлечённый текст, embeddings, история вопросов, API key GigaChat и provenance источников.

## Угрозы и контроли

| Угроза | Текущий контроль | Остаточный риск |
| --- | --- | --- |
| Prompt injection в документе | system prompt объявляет контекст недоверенным; документы не вызывают tools | модель может частично последовать атаке |
| Утечка ключа | `.env` исключён из Git; ключ не логируется и не возвращается API | доступ администратора к контейнеру |
| TLS downgrade | bundled официальный CA Минцифры; verification включена | необходимо отслеживать срок/ротацию CA |
| Path traversal | basename-нормализация и UUID-каталог | вредоносный, но допустимый файл |
| Zip bomb/макрос | zip не поддерживается; макросы не исполняются; лимит 25 МБ | сложный parser exploit |
| Утечка изображения страницы | приватный endpoint по UUID; fixed page path; remote PNG удаляется после vision | нет per-user ACL, политика удаления GigaChat внешняя |
| DoS через visual ingestion | один worker, 25 МБ, максимум 100 страниц, render timeout и advisory lock | стоимость до одной vision-операции на страницу |
| Межконтекстная утечка | каждый SQL retrieval фильтруется по `space_id` | нет per-user ACL |
| XSS из ответа | UI строит DOM сам; только валидные `http`/`https` URL становятся `<a>` с `noopener noreferrer`, остальной модельный текст остаётся text node | пользователь может перейти на вредоносную ссылку из загруженного документа |
| DoS/расход токенов | один worker, batch limit, advisory lock | нет пользовательской квоты |

## Условия безопасного развёртывания

Текущий релиз нельзя публиковать в Интернет: отсутствуют SSO, RBAC, CSRF-защита и tenant ACL.
Для внутреннего контура ограничьте порт 8000 доверенной сетью, шифруйте диски/backup, настройте
retention и получите разрешение на передачу корпоративных данных и изображений страниц внешнему
GigaChat API.
